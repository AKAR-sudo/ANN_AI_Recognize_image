# پڕۆژەی ناسینەوەی وێنەی مرۆڤ و ئاژەڵ بە بەکارهێنانی ANN
## Artificial Neural Networks (Deep Res-MLP) & Computer Vision

ئەم پڕۆژەیە تایبەتە بە کۆرسی زانکۆیی **Artificial Neural Networks (ANN)** بۆ ناسینەوە و پۆلێنکردنی وێنەی پێنج پۆلی سەرەکی:
1. 🧑 **مرۆڤ (Human)**
2. 🐶 **سەگ (Dog)**
3. 🐱 **پشیلە (Cat)**
4. 🐦 **باڵندە (Bird)**
5. 🐴 **ئەسپ (Horse)**

---

### 🧠 تەلارسازی مۆدێلەکە (Deep Residual ANN Architecture):
* **جۆری تۆڕی دەماری:** Deep Residual Multi-Layer Perceptron (Res-MLP ANN)
* **ژمارەی چینە شاردراوەکان:** ٧ چینی قووڵ (7 Deep Hidden Layers)
* **کۆی پارامیتەرەکانی ڕاهێنراو:** نزیکەی **١٤.٩ ملیۆن کێشی ماتماتیکی**
* **تەکنیکە زانستییەکان:**
  - **Skip Connections ($x + F(x)$):** پارێزەری سەرەکی دژ بە نەمانی داتاشراوەکان (Vanishing Gradients).
  - **فەنکشنی کاراکردنی GELU:** بۆ نەهێشتنی کێشەی مردنی نۆدەکان (Dying ReLU).
  - **دوو ئاستی نۆرماڵایزەیشن:** LayerNorm بۆ چینە سەرەتاییەکان و BatchNorm1d بۆ پۆلێنکردنی کۆتایی.
  - **فەنکشنی خەمڵاندنی هەڵە:** Label Smoothing Cross-Entropy بە کێشی هاوسەنگکراوی خودکار ($w_c$).

### 🔬 شیکاری زانستی ئەنجامەکان (In-Depth Technical Analysis):

1. **بۆچی ئەسپ (Horse) بەرزترین وردبینی هێنا (74.1% Precision / 0.75 F1-Score)؟**  
   پەیکەری لەشی ئەسپ خاوەنی قەبارەیەکی گەورە و شێوەیەکی ستوونی و درێژە کە تەنانەت تۆڕی دەماری تەختیش لە ڕێگەی دابەشبوونی پیکسڵەکانی پاشبنەما و تەنەکەوە زۆر بە ئاسانی لە پشیلە، سەگ، و باڵندە جیای دەکاتەوە.

2. **بۆچی سەگ و پشیلە ئەنجامەکەیان لە یەکتر نزیکە (Cat 42% / Dog 43%)؟**  
   هەردوو ئاژەڵەکە خاوەنی چوارپەل، پێکهاتەی هاوشێوەی دەموچاو، و ڕەنگی فەرووی لێکچوون. چونکە تۆڕی دەماری تەخت (Dense ANN) بە وێکتەری یەک-ڕەهەندی کار دەکات و کێرنڵی پێچراو بەکارناهێنێت، کەمێک لێکچوونی ڕەنگ لە پیکسڵەکاندا دروست دەبێت، کە ئەمەش خاڵێکی بەهێزی شیکارییە بۆ ڕاپۆرتی زانکۆ.

3. **دەوری چینە بازدەرەکان (Skip Connections):**  
   لە مۆدێلی سەرەتاییدا پشیلە و ئەسپ نمرەکەیان 0% بوو (لەبەر سڕبوونی نۆدەکان لە Vanishing Gradient). بەڵام بە یارمەتی Skip Connections و فەنکشنی GELU، هەموو ٥ پۆلەکە بە یەکسانی و بەبێ مردنی هیچ نۆدێک فێربوون.
