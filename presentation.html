سڵایدی ٤: تەلارسازی مۆدێل

تەلارسازی پێشکەوتوو: Deep Res-MLP ANN (٧ چینی قووڵ)

١. وەرگێڕانی وێنە
  • وێنە دەگۆڕدرێت بۆ وێکتەری مانایی 1,280 ڕەهەند.
  • ئەم وێکتەرە زانیاری چاو، گوێ، و شێوەی لەش دەپارێزێت و بە تەواوی سەربەخۆیە لە شوێنی پیکسڵ.
٢. بلۆکی بازدەر (Res-MLP)
  • Layer 1: Linear(1280 → 512) + LayerNorm + GELU
  • Residual Block: Linear(512 → 256) → Linear(256 → 512)
  • Skip Connection: $x + \mathcal{F}(x)$ ناهێڵێت گرادیێنتەکان بمرن.
٣. پۆلێنکردنی فرە-پۆل
  • Layer 4: Linear(512 → 256) + BatchNorm1d
  • Layer 5: Linear(256 → 128) + BatchNorm1d
  • Output Head: Linear(128 → 5) لۆجیتسی ٥ پۆلەکە → Softmax
سڵایدی ٥: یاسا ماتماتیکییەکان

هاوکێشە بیرکارییەکان و بنەما زانستییەکان

١. یاسای بازدانی گرادیێنت (Skip Connection)
y = GELU( x + F(x, {W}) )
لە کاتی Backpropagation دا، بوونی ماتریکسی یەکە ($I$) لە هاوکێشەی داتاشیندا زامنی ئەوە دەکات گرادیێنت قەت نەبێتە صفر (ڕێگری لە Vanishing Gradient).
٢. فەنکشنی کاراکردنی پێشکەوتوو (GELU)
GELU(x) = x * Phi(x) = x * P(X ≤ x)
لەبەر ئەوەی بە پێچەوانەی ReLU گرادیێنتی نەرێنییە بچووکەکان بە نەرمی دەهێڵێتەوە، ڕێگری کرد لە مردنی نۆدەکان (Dying ReLU Problem).
٣. هاوکێشەی سۆفتماکس (Multi-Class Softmax)
P(class c) = exp(z_c) / Σ exp(z_j)
لۆجیتسە خاوەکان دەگۆڕێت بۆ دابەشبوونی ئەگەر لە نێوان [0, 1] بە جۆرێک کە کۆی هەر ٥ ئەگەرەکە یەکسان دەبێت بە 1.0 (100%).
٤. فەنکشنی هەڵە (Cross-Entropy Loss)
Loss = - Σ q_c * log(p_c)
بەکارهێنانی Label Smoothing ($\alpha=0.08$) ناهێڵێت مۆدێل کێشەکانی لەسەر پۆلێک تووشی لەبەرکردنی لەڕادەبەدەر (Overconfidence) ببن.
سڵایدی ٦: تاقیکردنەوەی تێنسەر

لە پیکسڵەوە بۆ بڕیار — گەشتی بیرکاری وێنەی سەگ (0 بۆ 100)

  • قۆناغی چوونەژوورەوە: وێنەی سەگ ($800 \times 600$) لە دیسکەوە دەخوێندرێتەوە و ڕێکدەخرێت بۆ $128 \times 128 \times 3$.
  • ئاساییکردنەوە: پیکسڵەکان سفر-مەرکەزی دەکرێن بە $\frac{x - \mu}{\sigma}$ بەپێی کەناڵەکانی سوور و سەوز و شین.
  • وێکتەری مانایی: تێنسەرەکە تەخت دەکرێت بۆ وێکتەری $1 \times 1280$ نۆدی تایبەتمەندی (e).
  • لێکدانی ماتریکسی: $z_1 = e W_1^T + b_1$ تێپەڕین بەناو ٥١٢ و ٢٥٦ و ١٢٨ نۆد لەگەڵ بلۆکی بازدەر $x + F(x)$.
  • لۆجیتسی خاو: پاش لێکدانی چینی کۆتایی، پێنج ژمارەی خاو بەرهەمدێن:
    z = [Bird: -1.45, Cat: +0.82, Dog: +3.28, Horse: -0.95, Human: -1.70]
  • دەرئەنجامی Softmax: لەبەر ئەوەی $e^{3.28} \approx 26.58$ دەبێت و زۆر بەسەر هەموواندا زاڵە:
    P(Dog) = 89.6% 🐶 | P(Cat) = 7.7% | P(Horse) = 1.3% | P(Bird) = 0.8% | P(Human) = 0.6%
  • بڕیاری کۆتایی: بە فەنکشنی $\arg\max$ پۆلی دووەم هەڵدەبژێردرێت ──► سەگ (Dog) بە دڵنیایی تەواو!
